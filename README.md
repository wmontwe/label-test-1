# label-test-1

A sample repository to test and manage GitHub labels.

## Purpose

This repository is used to test GitHub label configurations, including:
- Defining custom labels with colors and descriptions
- Automating label management via GitHub Actions
- Testing label-based workflows

## Labels

Labels are defined in [`.github/labels.yml`](.github/labels.yml) and are automatically synced to this repository via the [Label Sync workflow](.github/workflows/labels.yml).
